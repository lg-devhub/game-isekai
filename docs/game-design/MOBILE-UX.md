# MOBILE-UX — Diretrizes de Interface e Usabilidade Educativa Touchscreen

Este documento define as diretrizes de interface do usuário, ergonomia móvel e acessibilidade para **Echoes of the Veil**, assegurando uma navegação confortável, fluida e clara para o público de **12 a 17 anos** em smartphones Android.

---

## 1. Ergonomia Touchscreen em Modo Retrato (Portrait)

O jogo opera com orientação vertical obrigatória (9:16 base), permitindo que adolescentes joguem confortavelmente segurando o aparelho com uma única mão durante trajetos ou momentos livres:

```
┌─────────────────────────────────┐
│     [ÁREA DE LEITURA E CENA]    │ ◄── Zona Superior (Passiva):
│ Cenário 2D / Diálogo com Busto  │     Foco visual, leitura e contemplação.
├─────────────────────────────────┤
│    [ÁREA DO CÓDICE & ENUNCIADO] │ ◄── Zona Central:
│ Pistas / Equações / Documentos  │     Exibição clara de dados e gráficos.
├─────────────────────────────────┤
│    [ZONA DE AÇÃO DO POLEGAR]    │ ◄── Zona Inferior (Thumb Zone):
│ Teclado Diegético / Seletores / │     Botões de avanço, diário, dicas e
│ Atalho Rápido para o Códice     │     confirmação de hipóteses.
└─────────────────────────────────┘
```

---

## 2. Acesso Instantâneo ao Códice do Conhecimento

A barra inferior permanente da interface contém quatro atalhos essenciais:
1. **Diário de Deduções:** Pistas e contradições colhidas no caso atual.
2. **Códice do Conhecimento:** Consulta imediata offline a resumos e fórmulas de matemática, lógica, linguagem e ciências.
3. **Inventário Forense:** Itens examináveis com zoom e rotação.
4. **Menu / Configurações:** Ajuste de áudio, acessibilidade e dificuldade.

---

## 3. Apresentação de Dados Complexos em Telas Pequenas

- **Equações e Fórmulas:** Apresentadas com tipografia limpa, grande e espaçada, evitando aglomeração de símbolos.
- **Grades de Dedução (Matrizes):** Células grandes de toque simples que alternam entre *Vazio*, *Verdadeiro (Círculo Verde/Símbolo ✔)* e *Falso (Xis Vermelho/Símbolo ✖)*.
- **Teclado Virtual Diegético:** Quando um enigma exige entrada de palavras ou números, a interface abre um teclado interno estilizado de pedra/bronze, evitando que o teclado do sistema operacional sobreponha o enunciado.
- **Acessibilidade Cromática:** Nenhuma informação é transmitida unicamente pela cor. Estados sempre incluem formas geométricas ou ícones identificadores.
